# Project: TGSheerHeartAttack

## Directory Overview

This directory contains an Android application and an Arduino project. The project is themed around "Sheer Heart Attack" from the anime/manga "JoJo's Bizarre Adventure".

The Android application is the primary component, while the Arduino part appears to be in the early stages of development or a placeholder.

## Key Files

*   `App/`: The Android application.
    *   `App/app/src/main/java/com/github/TechGinus/TGSheerHeartAttack/MainActivity.kt`: The main activity of the Android app. It currently features a button that plays a sound.
    *   `App/app/src/main/res/raw/kocchi_wo_miro.mp3`: The sound file played by the app.
    *   `App/app/srcsrc/main/java/com/github/TechGinus/TGSheerHeartAttack/SerialBluetooth.kt`: A placeholder file for Bluetooth communication.
*   `Arduino/SheerHeartAttack/SheerHeartAttack.ino`: The Arduino sketch. It is currently empty.

## Building and Running

### Android App

To build and run the Android app, open the `App/` directory in Android Studio and run it on an emulator or a physical device.

### Arduino

The Arduino code is not yet implemented. To use it, you would typically open `Arduino/SheerHeartAttack/SheerHeartAttack.ino` in the Arduino IDE, select your board and port, and upload the sketch.

## Development Conventions

The project is in its early stages, so there are no established conventions yet. The Android app is written in Kotlin.
